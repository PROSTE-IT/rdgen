# PROSTE IT RustDesk project

The canonical project context is stored in the private RDBK repository. Before
changing this project, read `rdbk/docs/PROSTE_IT_RUSTDESK.md` in this workspace
or the same file on the `PROSTE-IT/rdbk` branch `feature/shared-address-book`.

This workspace contains three independent Git repositories. Never commit the
contents of `rustdesk/` or `rdbk/` to the `rdgen` repository. Work and commit
in the repository that owns the changed files.

Do not add credentials, API tokens, customer data, production `.env` files, or
the address-book spreadsheet to Git.
